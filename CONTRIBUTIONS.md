# Dan’s contribution ledger

This fork adds an interface and checkable software work around Rosson’s published
research. It does not take credit for the original cipher key, readings, English
translations, or discovery claims.

| Work | Evidence included here | Limit |
|---|---|---|
| Landing page and reading room | Buildless HTML/CSS/JavaScript, two public source texts, source hashes, and integrity tests | Presents existing provisional readings. No image inference or new translation. |
| Saved-artifact verification | Independently authored scorer, unchanged pinned public inputs, method, licenses, and ten test groups | Compares exposed, model-assisted references. No independent expert ground truth or proof of blinding. |
| OOV history repair | [Draft upstream PR #1](https://github.com/pangoleen/desportes-1593/pull/1), four packaged synthetic test groups documented there | Open and unmerged when checked November 1, 2026. Not applied to this showcase branch. No measured manuscript-accuracy gain. |

The scorer’s expected result is four glyph edits over 1,301 reference glyphs and
23 letter edits over 1,369 reference letters. It reports unresolved-name coverage
separately. This page already has been inspected during development.

## What remains open

Independent manuscript reading, writer attribution, cover names, fresh concealed
labels, original recognizer artifacts, and end-to-end reproduction need their own
evidence. The original English already existed. Additional local research and
prototype work is not bundled or presented as publicly reproduced by this fork.

Desportes is a 1593 Catholic League political cipher. Preliminary Dead Sea Scroll
glyph work is a separate study. Cryptic B is not deciphered by this project.
