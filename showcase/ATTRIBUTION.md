# Credits and provenance

Paolo Rosson with Claude (Anthropic), *Two cipher letters of July 1593, read for
the first time*, 2026, https://github.com/pangoleen/desportes-1593.

Satoshi Tomokiyo reconstructed the key. Daniel Bourdeau published an earlier
attempt and source identification, notes, and labels used by Rosson. The original
[research README](../README_UPSTREAM.md) retains the full account.

Dan O’Leary, working with Codex, developed Reloaded’s interface and independent
saved-artifact verifier. This showcase adapts the established private Reloaded
paper/ink/bronze design. Its reader uses only public text and credits the existing
English translation to Rosson.

French source notes and English translations come from
`reading/f189_reading.txt` and `reading/f186_reading.txt` at upstream commit
`33c854af9d1a005e2d4fbb034a61c37f3682c6f6`. SOURCE_MANIFEST.json binds their bytes.
The generated bundle separates the TRANSLATION section from the French and notes,
preserving the remaining characters and uncertainty. The homepage excerpts that
published text.

Readings, translation, and adapted commentary retain CC BY 4.0 attribution.
Original showcase code is MIT, as specified in LICENSE. The cover and typeset
excerpt are interface artwork, not manuscript facsimiles.

No BnF image is added. Links identify the Gallica originals. Existing reduced
crops stay unchanged and subject to separate BnF terms in
[LICENSE.md](../LICENSE.md). Text and code licenses do not grant image rights.

The private Site’s access configuration, full scans, raw research, execution
approvals, and history are not bundled. The selected showcase and verifier release is authorized for this public fork.
Other private project material remains excluded.
