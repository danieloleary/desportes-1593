What is still open?

Independent manuscript review, unresolved names, original pipeline artifacts and the full recognition run remain separate work. This fork does not claim a new decipherment or improved manuscript accuracy.

Desportes concerns the Catholic League’s political cipher in 1593. Separate preliminary Dead Sea Scroll glyph work has not deciphered Cryptic B and is not included here.
